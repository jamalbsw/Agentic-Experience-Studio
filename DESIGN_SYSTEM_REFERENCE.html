Spacing Scale

All spacing uses a 4px base unit scale. Use CSS variables, never arbitrary values.

Variable Value Usage
--gap-xs4pxTiny gaps, letter-spacing
--gap-sm8pxSmall padding, margins
--gap-md12pxInternal element spacing
--gap-lg16pxComponent padding
--gap-xl24pxCard padding, major spacing
--gap-2xl32pxSection spacing
--gap-3xl40pxCard margins
--gap-4xl48pxLarge section gaps

Responsive Spacing Example

padding: clamp(24px, 4vw, 38px);  /* Fluid between 24px and 38px */
gap: clamp(36px, 7vw, 92px);      /* Scales with viewport */

Buttons

Button States

Button Rules

  • Minimum height: 48px for touch targets
  • Primary button: use --blue background
  • Secondary button: transparent with --sky text
  • Focus outline: 2px solid --sky with 3px offset
  • Hover: transform translateY(-1px) and darker blue
  • Text: 600 weight, 0.92rem size

Button CSS

button {
  min-height: 48px;
  padding: 12px 18px;
  border: 1px solid #168AB9;
  border-radius: 10px;
  background: var(--blue);
  color: #fff;
  font-weight: 600;
  cursor: pointer;
  transition: background-color .16s, transform .16s;
}

button:hover {
  transform: translateY(-1px);
  background: #0A8EC5;
}

button:focus-visible {
  outline: 2px solid var(--sky);
  outline-offset: 3px;
}

Form Elements

Form Structure

Form Rules

  • Labels must use --accent color (#D8A5FF)
  • Input minimum height: 48px
  • Input border: rgba(143,211,240,.24)
  • Input focus: 2px --sky outline with 2px offset
  • Error text: #FFB4AB color
  • Helper text: --muted color, smaller size

Rules & Standards

✅ DO

  • Use CSS variables for all colors and spacing
  • Use clamp() for responsive sizing
  • Follow typography hierarchy table exactly
  • Use subtle borders: rgba(143,211,240,.2)
  • Apply orange-yellow (#D8A5FF) sparingly for visual hierarchy
  • Test at 760px and 420px breakpoints
  • Include focus states for accessibility
  • Use meaningful semantic class names

❌ DON'T

❌ Never use white borders

border: 1px solid white; ← Wrong

border: 1px solid rgba(143,211,240,.2); ← Correct

❌ Never use arbitrary spacing

margin: 15px; ← Wrong (not on 4px scale)

margin: var(--gap-xl); ← Correct (24px)

❌ Never use inline styles

<div style="color: blue;"> ← Wrong

<div class="text-primary"> ← Correct

❌ Never use fixed font sizes

font-size: 20px; ← Wrong (not responsive)

font-size: clamp(1.2rem, 3vw, 1.5rem); ← Correct

❌ Never forget focus states

Interactive elements MUST have visible focus indicators

outline: 2px solid var(--sky);

Component Checklist

Before committing any new component, verify:

  • Colors use CSS variables only
  • Spacing uses 4px scale
  • Typography follows hierarchy
  • Borders are subtle (not white)
  • Has focus state for accessibility
  • Responsive at 760px and 420px
  • Touch targets minimum 48px
  • Class names follow kebab-case convention
  • No inline styles
  • Text contrast meets WCAG AA (4.5:1)
